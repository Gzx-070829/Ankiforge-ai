# Optional document backends (v0.14.1)

Docling, MarkItDown, and Pandoc are optional local integrations, not bundled AnkiForge components. They are lazy, absent-safe, disabled by default, and only process an explicitly selected local file after user choice. Open **Document capabilities / 支持能力**, review the detected state, and choose at most one available backend for the current window. Choose **Use native Core only / 仅使用原生 Core** to turn an earlier selection off. Pandoc requires choosing the already-installed `pandoc`/`pandoc.exe` explicitly; the dialog reports whether that selection was accepted. This selection is session-only and is never persisted. The add-on never runs pip, downloads a model, installs an executable, enables a third-party plugin, uploads a file, or accepts a URL. Backend failure is shown with a safe retry/fallback action and leaves native Core usable. “Detected” only describes local capability discovery; Docling/MarkItDown must still pass a real Anki embedded-runtime launch/import acceptance test for each supported Anki build.
