# Pandoc setup (v0.14.1)

Pandoc is a separately installed external executable, not a bundled library. In **Document capabilities / 支持能力**, choose the already-installed `pandoc`/`pandoc.exe`; the dialog shows whether the path was accepted. The absolute path stays only in the current window and is not shown in the main queue or persisted. Only that fixed executable name is accepted. Filters, PDF engines, includes, and remote resources are not enabled. Check Pandoc's GPL-2.0-or-later license and your own environment before use.
